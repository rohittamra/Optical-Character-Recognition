# 📱 Android Optical Character Recognition (OCR)

An Android application that uses Optical Character Recognition (OCR) technology to detect and extract text from images. The application enables users to convert printed or handwritten content into editable digital text directly from their Android device.

---

## 🚀 Features

* 📷 Capture images using the device camera
* 🖼️ Select images from the gallery
* 🔍 Extract text from images using OCR
* 📝 Display recognized text in an editable format
* 📋 Copy extracted text for use in other applications
* 📱 Simple and user-friendly Android interface

---

## 🛠️ Technologies Used

* Android SDK
* Java
* Android Studio
* Gradle Build System
* OCR Engine (Tesseract OCR / Text Recognition Library)

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/<your-username>/Optical-Character-Recognition.git
cd Optical-Character-Recognition
```

### Open in Android Studio

1. Launch Android Studio.
2. Select **Open an Existing Project**.
3. Choose the cloned repository folder.
4. Allow Gradle Sync to complete.

### Build and Run

1. Connect an Android device or start an emulator.
2. Click **Run** ▶️ in Android Studio.
3. Install and launch the application.

---

## 📖 How It Works

1. User selects or captures an image.
2. The image is processed by the OCR engine.
3. Text is detected and extracted.
4. The recognized text is displayed on the screen.
5. Users can copy, edit, or save the extracted content.
